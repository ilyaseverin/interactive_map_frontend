# Карта Боевой Славы Липецкой области

## Описание

Интерактивная карта памятников, мемориалов, мемориальных досок и воинских захоронений Липецкой области времен Великой Отечественной войны.

## Структура разделов

Раздел «Карта Боевой славы Липецкой области» содержит 4 подраздела:

### 1. История Липецкой области в годы ВОВ

- Краткое описание истории региона в годы войны
- Статистика по муниципальным образованиям:
  - Количество ушедших на фронт липчан
  - Количество погибших липчан
  - Деление по районам

### 2. Памятники и мемориалы

- Тип: `памятник/мемориал`
- Цвет маркера: Красный (#dc2626)
- Отображение всех памятников и мемориалов на территории области
- Количество объектов по муниципальным образованиям

### 3. Мемориальные доски

- Тип: `мемориальная доска`
- Цвет маркера: Синий (#2563eb)
- Отображение всех мемориальных досок на территории области
- Количество объектов по муниципальным образованиям

### 4. Воинские захоронения

- Тип: `воинское захоронение`
- Цвет маркера: Зеленый (#059669)
- Отображение всех воинских захоронений на территории области
- Количество объектов по муниципальным образованиям

## Функциональность

### Навигация

- Подразделы показываются при наведении на главное меню
- Главный пункт меню "Все объекты" кликабелен
- Быстрые фильтры для каждого типа объектов

### Карта

- ✅ Адаптивность под все устройства (включая мобильные)
- ✅ Масштабирование карты
- ✅ Кластеризация точек при отдалении
- ✅ Построение маршрута до точки через сторонние навигационные программы
  - На мобильных: Яндекс.Навигатор
  - На десктопе: Google Maps

### Информация о точках

При нажатии на точку отображается:

- 🖼️ Превью изображения (если доступно)
- 📛 Тип объекта (бейдж с цветовой кодировкой)
- 📝 Название объекта
- 📄 Описание (краткая характеристика)
- 📍 Район (муниципальное образование)
- 🏠 Адрес объекта
- 🎥 Видеоролик (если доступен)
- 🗺️ Кнопка "Построить маршрут"

### API Endpoint

**URL:** `/api/battle-glory-points`

**Метод:** GET

**Query параметры:**

- `point_type` - Фильтр по типу объекта
  - `памятник/мемориал`
  - `мемориальная доска`
  - `воинское захоронение`
- `municipality` - Фильтр по муниципальному образованию
- `page` - Номер страницы (по умолчанию: 1)
- `pageSize` - Количество объектов на странице (по умолчанию: 10000)

**Пример запроса:**

```
GET /api/battle-glory-points?point_type=памятник/мемориал&municipality=Елец
```

**Формат ответа:**

```json
{
  "data": [
    {

      "title": "Мемориальный комплекс на пл. Революции",
      "description": "Мемориальный комплекс Вечный огонь...",
      "point_type": "памятник/мемориал",
      "municipality": "Елец",
      "address": "г. Елец",
      "formatted_address": "Липецкая область, Елец, площадь Революции",
```

### Strapi Content Type

Должен существовать content type `battle-glory-point` со следующими полями:

- `title` (Text) - Название объекта
- `description` (Rich Text) - Описание объекта
- `point_type` (Enumeration) - Тип объекта
  - памятник/мемориал
  - мемориальная доска
  - воинское захоронение
- `municipality` (Text) - Муниципальное образование
- `address` (Text) - Адрес
- `formatted_address` (Text) - Форматированный адрес
- `coordinates` (JSON) - Координаты {lat: number, lng: number}
- `region` (Text) - Регион
- `object_name` (Text) - Название объекта
- `image` (Media) - Основное изображение
- `preview_image` (Media) - Превью изображение
- `video` (Media) - Видеоролик

### Переменные окружения

Создайте `.env.local` файл:

```bash
NEXT_PUBLIC_STRAPI_URL=http://localhost:1337
```

Для продакшена обновите URL на адрес вашего Strapi сервера.

## Требования к данным

### Минимальные требования

- Не менее 400 объектов на карте
- Не менее 50 видеороликов
- Каждый видеоролик:
  - Формат: MOV или MP4
  - Разрешение: Full HD (1920x1080)
  - FPS: 25 или 50
  - Стереозвук
  - Озвучен профессиональным голосом
  - Продолжительность: не менее 1 минуты

### Информация об объектах

Для каждого объекта необходимо:

- Муниципальное образование
- Вид объекта
- Наименование объекта
- Краткая характеристика (не менее 5 предложений)
- Фотография

## Использование

### Открыть карту

Перейдите на страницу: [http://localhost:3000/battle-glory](http://localhost:3000/battle-glory)

### Фильтрация

1. **Наведите** на кнопку "Все объекты" для отображения выпадающего меню
2. **Кликните** на нужный тип объектов
3. Используйте **быстрые фильтры** для переключения между типами

### Работа с точками

1. **Кликните** на маркер для открытия информации
2. **Нажмите** "Построить маршрут" для навигации
3. **Кликните** вне маркера для закрытия информации

### Встраивание на сторонние сайты

API поддерживает CORS и может использоваться на сторонних ресурсах.
