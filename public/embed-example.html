📋 Примеры кода для встраивания

HTML - Базовое встраивание
<iframe src="http://localhost:3000/embed" width="100%" height="600" frameborder="0" style="border: 0;" allowfullscreen ></iframe>
HTML - С параметрами
<iframe src="http://localhost:3000/embed?lng=37.6173&lat=55.7558&zoom=10&clustering=true" width="100%" height="600" frameborder="0" style="border: 0;" allowfullscreen ></iframe>
JavaScript - Динамическое создание
function embedMap(containerId, options = {}) { const { lng = 37.6173, lat = 55.7558, zoom = 4, width = '100%', height = '600px', clustering = true } = options; const params = new URLSearchParams({ lng: lng.toString(), lat: lat.toString(), zoom: zoom.toString(), clustering: clustering.toString() }); const iframe = document.createElement('iframe'); iframe.src = `http://localhost:3000/embed?${params}`; iframe.width = width; iframe.height = height; iframe.frameBorder = '0'; iframe.style.border = '0'; iframe.allowFullscreen = true; document.getElementById(containerId).appendChild(iframe); } // Использование embedMap('map-container', { zoom: 10 });
React - Компонент
import React from 'react'; function MapEmbed({ lng = 37.6173, lat = 55.7558, zoom = 4 }) { const src = `http://localhost:3000/embed?lng=${lng}&lat=${lat}&zoom=${zoom}`; return ( <iframe src={src} width="100%" height="600px" frameBorder="0" style={{ border: 0 }} allowFullScreen title="Интерактивная карта" /> ); }

⚙️ Доступные параметры URL

Параметр Тип По умолчанию Описание
lng number 37.6173 Долгота центра карты
lat number 55.7558 Широта центра карты
zoom number 4 Уровень зуммирования (0-18)
clustering boolean true Включить кластеризацию точек
